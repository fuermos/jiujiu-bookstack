# 福尔摩斯探案全集——侦探推理方法论

## How to Use This Skill
本书不是简单的故事集，而是柯南道尔以华生回忆录形式包装的**推理方法论教材**。本 skill 提炼福尔摩斯的核心方法（演绎法、观察重构、案情叙事），适用于：

- 写作侦探/悬疑小说时构建推理链
- 侦探游戏中设计谜题与线索
- 用户研究/取证分析——从细微行为推断完整背景
- 商业场景的"侦探式"问题诊断
- 提升个人的观察力与逻辑推理能力

调用方式：当你面对 `需要从有限线索推断完整故事`、`需要解谜/破案`、`需要构建悬念` 类任务时，按 `Core Frameworks` → `patterns.md` → `chapter` 顺序索引。

## Core Frameworks

### Framework 1: 演绎法（The Science of Deduction）
华生以为"演绎"是从一般到个别，福尔摩斯纠正：真正的演绎是从**观察个别事实**出发，推断出更普遍的结论，再回溯到个别应用。三步走：
1. **观察**：收集所有可感知的事实（包括看起来无关的）
2. **推理**：用排除法排除不成立的假设
3. **验证**：用新事实回测假设

核心原则：**"排除不可能的，剩下的无论多么不合情理，就是真相"**——福尔摩斯在《四签名》中给出的方法论基石。

### Framework 2: 观察—重构术（Observation & Reconstruction）
福尔摩斯能在初次见面的几分钟内，从一个人的指甲、袖口、靴子、表情、走路姿态推断出他的职业、习惯、最近经历。本质是把人当作**痕迹系统**来读：
- 衣着 = 身份与经济状况
- 手部 = 职业与近期活动
- 步态 = 健康与心理状态
- 语言 = 教育与来源

此框架贯穿全集（《血字的研究》《四签名》开篇即是示范）。

### Framework 3: 案情陈述结构（Statement of the Case）
华生在《四签名》中把案情交代给福尔摩斯时，遵循固定结构：**时间—地点—人物—事件—已知条件—未知问题**。福尔摩斯用此结构反向推导（"案情重构"）：
1. 听完陈述，立即列出**所有可能性**
2. 标记每个可能性的**关键证伪点**
3. 只考察能最快排除多数假设的维度

### Framework 4: 案情重构 vs 案情陈述（Reconstruction vs Statement）
本书最重要的元方法：每桩案件都有**两个版本**——
- **版本A（警方/证人）**：基于表面证据，线性叙事，通常错过关键
- **版本B（福尔摩斯）**：从结尾反推，按犯罪者必须做的动作重构链条

福尔摩斯的所有突破都来自发现版本A中的**逻辑裂缝**——时间不合理、动机不成立、证人不可能看到或做某事。

### Framework 5: 探案小队（Baker Street Irregulars）
福尔摩斯不亲自跑腿，而是组织**街头流浪儿小队**搜集情报。这是"分布式情报网络"的早期范式：
- 明确任务（找什么、看什么、跟踪谁）
- 给予报酬与激励机制
- 小孩比成人更不引人注目
- 信息分层回收（一条街、一片区域）

**When to use this**：当你需要大规模并行搜集情报时。

### Framework 6: 戏剧性死而复生（Narrative Resurrection）
柯南道尔在《最后一案》让福尔摩斯坠落身亡，读者愤怒；几年后用"假死"机制在《空屋》中复活。这是**故事性架构的方法**：
- 高价值角色不轻易死亡
- 死亡如必须发生，留逻辑空间（目击者少、体貌被毁等）
- 复活必须给出**反向证据链**，让读者"啊哈"而非"被骗"

### Framework 7: 贝尔启发法（The Bell Method）
柯南道尔在爱丁堡大学师从约瑟夫·贝尔，贝尔训练学生"像观察左撇子修鞋匠或高原兵团退役中士那样**精确观察**"。此方法贯穿全集：
- 不要问"你看到了什么"
- 要问"那个人做了什么、穿什么、习惯如何——这些透露了他的过往"
