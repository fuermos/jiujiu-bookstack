# 爱丽丝迷案（Oxford Murders / Crímenes imperceptibles）

## How to Use
本作是阿根廷作家吉列尔莫·马丁内斯的学院派推理小说。主角是牛津大学研究数理逻辑的阿根廷留学生，因研究手写笔迹还原课题，卷入由符号学家阿瑟·塞尔登和警探皮特森主导的一系列"无法察觉的犯罪"。本 skill 用于：
- 学习"数理逻辑 × 推理小说"的叙事骨架
- 提取数学符号与命案之间的映射技法
- 借鉴作者用学术对话驱动悬念的写作手法
- 复盘"完美犯罪 = 找错凶手案件"这一核心命题

## Core Frameworks

### 1. 塞尔登命题：完美犯罪的新定义
"完美犯罪，不是那些没有被侦破的无头案，而是找错了凶手的案件。"
- 框架核心：犯罪之"完美"不在于隐蔽，而在于归因错误。
- 操作含义：凶手主动制造一名替罪者，使调查方向从正确轨道滑向平行轨道。
- 在本作中的应用：凶手留下的每一枚"符号/数字/公式"都是经过设计的指认装置。

### 2. 符号–罪行对应链（Sign-Crime Correspondence）
- 每一起死亡都伴随一个数学/哲学符号（数字、公式、引文）。
- 符号既是死因（误导），也是破案密钥（真因）。
- 解读规则：**符号的表面意义是陷阱，结构意义才是入口**。

### 3. 手写还原：从静止图像推导过去
- 来源：主角的笔迹研究课题——用拓扑对偶定理从二维图像还原三维运笔。
- 哲学对位：博尔赫斯《皮埃尔·梅纳尔》——同样的字词，不同的生成过程。
- 推论：**结果相同 ≠ 过程相同**。在推理中，过程（动机链）比结果（罪行）更本质。

### 4. 逻辑的速度 vs 冲动的速度
- 逻辑推理：谨慎、可控、龟速，但产物必然且唯一。
- 灵感/冲动：轻快、偶然、"神助"，产物不可重复。
- 操作含义：分析一个人物，要看他选择用哪种速度思考——梅纳尔式还是塞万提斯式。

### 5. 数理逻辑人物群像（Functional Cast）
| 角色 | 功能 | 工具/武器 |
|---|---|---|
| 阿瑟·塞尔登 | 符号学导师 | 引文、文献 |
| 雷顿·霍华德 | 笔迹专家 | 化学、统计学 |
| 皮特森探长 | 经验侦探 | 现场、行为 |
| 艾米莉·布朗森 | 学术导师 | 拓扑对偶 |
| 主角（叙述者） | 中介观察者 | 哲学类比 |

### 6. 不完备性的叙事化
- 哥德尔不完备性定理：在足够强的形式系统中，必有真但不可证的命题。
- 推理应用：**犯罪现场永远存在无法由现场自身证明的真相**——必须引入外部"元系统"（目击者、动机、历史）。

### 7. 维特根斯坦边界（Whereof one cannot speak）
- 凡不可说的，应当沉默。
- 反讽用法：本作中"沉默"本身是角色的武器——雷顿的寡言、皮特森的玩笑、凶手的不在场证明。
